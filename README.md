# Impact Idol community directory

`communities.json` is the list of communities the Impact Idol mobile app offers in "Choose your community".
Served by GitHub Pages at https://piper5ul.github.io/impact-idol-directory/communities.json

To add a community: add one line with a unique `id`, the display `name`, and the server `url` (https only), then commit.
The app refreshes the list on launch and keeps its last good copy; the server must also be configured for the unified app
(Google/Apple sign-in audiences, chat allowlist, push, app-link files) before it is listed here.

Do not list staging, test, or unlisted communities here; this repository is public.
